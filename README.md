# 天淵實業 募資儀表板

天淵實業（8 吋微機電 Bolometer MEMS 產線 ／ 紅外線熱影像晶片 IDM 廠）的募資與營運歷程儀表板。單一 HTML 檔案，離線即可開啟，無需建置流程或伺服器。

## 內容

- **公司狀態列**：目前公開市場狀態（未上市／興櫃／IPO／上市上櫃）
- **公司快照**：經營團隊、主要投資者（含持股比例）、技術領域、供應鏈夥伴
- **募資與營運時間軸**：以年份為尺度的 SVG 時間軸，切分「產線籌建期」與「A輪」兩個階段
- **各階段大事紀**：依時間排序的募資／營運事件，含金額、投資人與結論摘要
- **市場情緒分析**：整理公開新聞中與天淵實業相關的市場／產業情緒訊號

## 使用方式

直接用瀏覽器開啟 `index.html` 即可，不需要任何建置步驟：

```bash
open index.html        # macOS
xdg-open index.html    # Linux
start index.html       # Windows
```

也可以放到任何靜態網站託管服務（GitHub Pages、Netlify、Vercel 等）直接上線。

## 技術說明

- 純 HTML + CSS + 原生 JavaScript，無任何建置工具或框架依賴
- 字型透過 Google Fonts CDN 載入（Archivo / IBM Plex Sans / IBM Plex Mono），其餘樣式與邏輯皆內嵌於單一檔案中
- 支援淺色／深色模式（跟隨系統 `prefers-color-scheme`），版面在桌面與行動裝置寬度下皆可正常顯示
- 資料（公司快照、時間軸階段、事件、情緒分析）以 JavaScript 物件陣列的形式寫在檔案內的 `<script>` 區塊中，更新資料即可直接編輯該區塊重新產生畫面

## 資料來源與限制

資料整理自天淵實業公司新聞曲線紀錄分析。金額依原始揭露幣別（新台幣）標示，未揭露者標示「未揭露」。公開資料未提及興櫃／上市櫃掛牌，狀態暫列未上市。情緒分析反映新聞紀錄中的市場／產業訊號，非投資人情緒調查數據。

**本頁僅彙整募資與營運里程碑，不構成投資建議。**
